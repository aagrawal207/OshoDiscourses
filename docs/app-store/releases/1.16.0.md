## Features

- **Apple Watch.** The Watch app controls the iPhone player and browses Continue
  Listening, Downloads and Bookmarks on the phone. Save to Watch copies a downloaded
  talk to the Watch for offline listening on Bluetooth headphones, and the Watch
  reports listening positions back to the phone. See [Apple Watch](../../apple-watch.md).
- **CarPlay (pending Apple approval).** CarPlay lists Continue Listening, Downloads
  and Bookmarks, and adds speed and bookmark buttons to Now Playing. Apple has not
  approved the CarPlay audio entitlement for this App ID. The normal build includes
  the CarPlay scene code but requests no entitlement, so CarPlay will not list the
  app. CarPlay ships to listeners only after approval and a build from the
  `OshoDiscoursesCarPlay` scheme. See [CarPlay](../../carplay.md).
- **iPad.** Sidebar navigation, a two-column player with the live transcript, adaptive
  grids, context menus, hover, keyboard shortcuts with Playback and View menus, and
  multiple windows. See [iPad and Mac](../../ipad-and-mac.md#interface).
- **Mac.** A Mac Catalyst build ("Optimize for Mac") of the same target and bundle ID,
  with DeepFilterNet, Now Playing and the menu bar. `DeepFilterBridge.xcframework`
  now has a Mac Catalyst slice. See [iPad and Mac](../../ipad-and-mac.md#mac-platform).

**Translated narration is deferred.** It was removed from `main` and preserved on
branch `wip/translated-narration-1.16` (commit `17c9039`) for a later release.
Neither the app, the metadata nor the screenshots for 1.16.0 include it.

### Mac distribution and the existing iPad app on Mac

The Mac build uses `com.agraabhi.oshodiscourses`, so it joins the existing app record
and keeps universal purchase, iCloud key-value sync and the tip products. A Mac that
installed the iPad app from the Mac App Store ("Designed for iPad"), as this
development Mac has, would receive the Catalyst build in its place once the macOS
platform is published.

  app name with the topic and supported audio languages.

  title, subtitle or category words. Rajneesh moves from the old subtitle into
  keywords alongside relevant topics and features.
- The description explains reading, discovery, offline listening, sound controls

  free functionality for people deciding whether to download.

is presentation copy rather than an indexed keyword field. No search-ranking or
conversion uplift has been measured yet.
