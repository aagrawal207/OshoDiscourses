# 1.16.0 listing refresh

**Status: prepared locally; App Store creation deferred.** On 2026-09-19 Apple
rejected creation of 1.16.0 while 1.15.0 (26) was `WAITING_FOR_REVIEW`:

> You cannot create a new version of the App in the current state.

The selected workflow keeps 1.15.0 in its review queue and prepares the 1.16.0
listing for after that release. No 1.16.0 version ID or build exists yet.

The README and artwork bundle were published to GitHub in commit `1401d6d`.
The public repository page was checked without authentication, and the README
and four gallery/hero image blobs matched the local files through the GitHub API.

## Prepared changes

- The GitHub README leads with a new hero, an official App Store badge and a
  nine-screen gallery. Feature text covers read-along transcripts, DeNoise,
  offline downloads, bookmarks, sleep timer and listening stats.
- Nine iPhone and nine iPad App Store images use real captures from **1.15.0 (26)**.
  The proposed work for 1.16.0 is a listing refresh, with no additional app
  functionality implemented in this task.
- [English metadata](../metadata/version/1.16.0/en-US.json) provides the description,
  promotional text, keywords, URLs and listing-refresh release note.
- [The screenshot bundle](../screenshots/1.16.0/README.md) contains raw captures,
  ordered PNGs, overview images and file checksums.

## Resume after 1.15.0 releases

```bash
python3 Tools/StoreAssets/prepare.py
python3 Tools/StoreAssets/prepare.py --apply
```

The apply command prepares only the editable 1.16.0 listing and its image sets.
It verifies the new largest iPhone/iPad sets before clearing older optional iPhone
sizes on that new localization. It protects the source version's screenshot IDs.
The live apply path cannot be exercised until Apple allows the new version.

For an eventual App Store submission, prepare a matching 1.16.0 binary, update its
review information, and verify the images still match that build. The captures
came from the local 1.15.0 (26) release candidate; this artwork task did not bump
the app's source version.
