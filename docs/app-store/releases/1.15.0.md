## App Review follow-up

Apple rejected build 25 under Guideline 2.1(b), saying the five associated tips
could not be found in the submitted binary, and Guideline 1.5, saying the GitHub
Issues Support URL lacked usable support information.

The build 25 IPA was rechecked and contains the tip-jar implementation and all
five product IDs. The Settings entry is enabled in Release. After the rejection,
the user reported completing a purchase successfully through TestFlight and then
provided physical-device recordings. The current 60.66-second walkthrough starts
on the iPhone Home Screen, launches Osho Talks, demonstrates the core screens and
shows all five tip prices. A US$3 Small tip sandbox purchase succeeds and the app's
count increases from two to three. The reason the reviewer could not find the
products has not been established.

The [public support page](https://github.com/aagrawal207/OshoDiscourses/blob/main/SUPPORT.md)
was published in commit `9304509` and verified without authentication. It provides
`aagrawal207@gmail.com` and support instructions. App Store Connect's English
Support URL for 1.15.0 was updated to that page.

Build 26 includes the corrected in-app feedback address, `aagrawal207@gmail.com`.
After it passed testing, signing and Apple's build processing, it was attached
to version 1.15.0. The rejected app review item was marked resolved, all six review
items were verified `READY_FOR_REVIEW`, and the existing submission was resubmitted.
