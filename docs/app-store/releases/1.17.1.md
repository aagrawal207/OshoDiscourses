## Included changes

- **Crash fix.** 1.17.0 crashed twice with `-[_UISceneHostingController
  _setSheetConfiguration:]`. Apple's language download prompt is now requested only
  from the visible Listen in Translation sheet and stacks on it; automatic continue
  never shows it. See [the investigation](../../crash-sheet-configuration.md).
- **Lock Screen player.** Speech rendering used a separate system audio session, and
  while a translation was being prepared iOS hid the Now Playing player for any audio.
  Rendering now uses the app's session.
- **Sponsor tip.** The US$100 one-time tip from build 37
  (`com.agraabhi.oshodiscourses.tip.sponsor`). At the owner's request, What's New
  (in-app and store) lists only the two fixes, not the tip.
